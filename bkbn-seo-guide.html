  4. Search Console ላይ ከታች ያሉትን እርምጃዎች ይከተሉ።

1. ለአንድ ፋይል (በእጅ ማስገባት)

<head> ውስጥ የሚገባ መስመር፦

<meta name="robots" content="noindex, nofollow">

2. ሁሉንም ሌሎች HTML በአንድ ጊዜ noindex የሚያደርግ ስክሪፕት

የBK/BN ፋይልዎ ስም index.html ካልሆነ፣ KEEP ውስጥ ያስተካክሉ። ከማሄድዎ በፊት repo ን backup ያድርጉ።
import os, re

KEEP = {"index.html"}   # ← የBK/BN ፋይል ስም (ብዙ ከሆነ በኮማ ይለዩ)
TAG = '<meta name="robots" content="noindex, nofollow">'

for root, dirs, files in os.walk("."):
    dirs[:] = [d for d in dirs if d not in (".git", "node_modules")]
    for f in files:
        if not f.lower().endswith(".html"):
            continue
        path = os.path.join(root, f)
        rel = os.path.relpath(path, ".").replace("\\", "/")
        if rel in KEEP:
            continue
        with open(path, encoding="utf-8") as fh:
            html = fh.read()
        if re.search(r'name=["\']robots["\']', html, re.I):
            print("ተዘሏል (አስቀድሞ አለው):", rel)
            continue
        new, n = re.subn(r"(<head[^>]*>)", r"\1\n" + TAG, html, count=1, flags=re.I)
        if n == 0:
            print("<head> አልተገኘም:", rel)
            continue
        with open(path, "w", encoding="utf-8") as fh:
            fh.write(new)
        print("noindex ተጨምሯል:", rel)

ማስኬጃ፦ python noindex.py

3. sitemap.xml (የBK/BN ዩአርኤል ብቻ)

YOUR-USERNAME እና YOUR-REPO ን በእርስዎ ይተኩ።
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://YOUR-USERNAME.github.io/YOUR-REPO/</loc>
  </url>
</urlset>

4. በGoogle Search Console

  1. Sitemaps → sitemap.xml ያስገቡ።
  2. የBK/BN ዩአርኤል → URL Inspection → Request indexing።
  3. የቆዩ ያልተፈለጉ ዩአርኤሎች → Removals → New request → Temporarily remove URL።
  4. noindex የተደረጉ ገጾች Google እንደገና ሲያነባቸው ቀስ በቀስ ይወጣሉ (ጥቂት ቀናት እስከ ሳምንታት)።
ማስጠንቀቂያ፦ robots.txt ውስጥ Disallow አይጨምሩ፤ Google noindex መለያውን እንዳያነብ ያደርገዋል። noindex ጥያቄ ነው እንጂ ጥበቃ አይደለም፤ ዩአርኤሉን ያወቀ ሰው ገጹን መክፈት ይችላል። ሙሉ ጥበቃ ከፈለጉ ያላለቁ ስራዎችን private repo ውስጥ ያስቀምጡ።
